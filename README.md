# 推進管 製造・出荷・在庫管理

ブラウザで製造、出荷、搬入、推進使用、空伏管の坑内付設使用を管理します。未共有時はブラウザ内、Microsoft接続時は案件の共有フォルダに更新履歴を保存します。

## 表からの編集

- 「1か月」「2か月」で表示を切り替えます。
- 出荷の数字をドラッグすると、出荷日を変更します。移動先に出荷があれば合算します。ドラッグ時に出荷予定全体を固定するため、移動によって自動出荷が追加発生しません。
- 製造・出荷・搬入・推進使用・坑内付設使用は、数量セルをダブルクリックして編集できます。Enterキーでも開けます。空欄は自動計算に戻す指定、0は作業なしです。
- 日進バーの両端で開始・終了日を変更し、中央をドラッグすると期間を移動します。範囲外では推進せず、範囲内でも休工日は使用しません。日別の数量指定はバーより優先されます。
- 下部の施工ペースでは、管番号区間と日付範囲を直接設定できます。管番号で再計算すると日付範囲の指定を解除します。2.5本／日などの自動使用数は小数を繰り越し、2本・3本のような整数で配分します。
- 「管種・用途」で推進用／空伏管（坑内付設用）を指定します。空伏管は推進の日進・完了本数から除外し、専用の使用欄で現場在庫を減らします。

## 継続して使える機能

Microsoft共有接続・案件切り替え、期間別の製造日量、休工日、開始前在庫、日別メモ、バックアップと読込、CSV、月別印刷を保持しています。既存の履歴形式を継続使用し、読込時に実績・日進・休工・施工開始日を初期化しません。

受領工程表は専用JSONを読み込み、案件の `referencePlan` に保存します。具体的な工事の日付や数量を公開ソースへ含める運用にはしません。参照予定を適用すると、製造・出荷・搬入の手入力指定を解除してその予定を使います。実績と施工ペースは保持します。

## 2026-11-16 製造開始・養生・完成日の計算

- カレンダー工場欄は「製造開始」「製造完了」「養生中（養生設定がある場合）」「工場在庫」。製造開始のセルをダブルクリックして製造本数と日別養生日数を入力し、その場で完成日を確認する。完成数は直接入力せず、製造日＋養生日数で算出する。日付を押した日別フォームからも入力できる。
- 完成日＝製造日＋養生日数（暦日、製造日を0日目）。日曜・祝日・年末年始も日数に含める。養生0日は同日完成。基本の養生日数より、製造日が該当する養生期間設定、その日だけの手入力指定の順に優先する。
- 工場在庫は開始前完成在庫＋完成累計−出荷累計。養生中は製造累計−完成累計として別集計。開始前在庫は完成済み扱い。完成前の手入力出荷は警告し、養生の途中の数量を完成として扱わない。養生0日では既存の日別数量を保持する。
- 「製造日・養生日数・完成日の確認」を開くと日別一覧を表示。完成数・完成日・養生中をCSVにも含め、印刷の製造完了欄も自動完成数とする。実績は記録した製造だけを使い、完成日当日の追加実績入力なしでも養生完了数を計算する。
- 「工程の設定」に養生期間（製造日の範囲と日数）を追加。養生期間・製造ペース・休工期間・施工の日付範囲で、終了日を変更→次行開始を翌日へ、開始日を変更→前行終了を前日へ連動。行追加は前行の翌日から。必要なら隣行を1日以上に調整し、後続／前行の境目も連動する。既存の保存済み期間を読込時に上書きはしない。
- 養生期間・製造ペース・施工日付範囲の追加行は「休止期間」に切替可能。養生／製造の休止は自動製造を0、施工の休止は自動使用を0にする。既存の手入力数量は優先し、製造済みの管の養生は休止中も暦日で進む。
