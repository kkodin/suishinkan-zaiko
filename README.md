# 推進管 製造・出荷・在庫管理

ブラウザで製造、出荷、搬入、推進使用、空伏管の坑内付設使用を管理します。未共有時はブラウザ内、Microsoft接続時は案件の共有フォルダに更新履歴を保存します。

## 表からの編集

- 「1か月」「2か月」で表示を切り替えます。
- 出荷の数字をドラッグすると、出荷日を変更します。移動先に出荷があれば合算します。ドラッグ時に出荷予定全体を固定するため、移動によって自動出荷が追加発生しません。
- 製造・出荷・搬入・推進使用・坑内付設使用は、数量セルをダブルクリックして編集できます。Enterキーでも開けます。空欄は自動計算に戻す指定、0は作業なしです。
- 日進バーの両端で開始・終了日を変更し、中央をドラッグすると期間を移動します。範囲外では推進せず、範囲内でも休工日は使用しません。日別の数量指定はバーより優先されます。
- 下部の施工ペースでは、管番号区間と日付範囲を直接設定できます。管番号で再計算すると日付範囲の指定を解除します。2.5本／日などの自動使用数は小数を繰り越し、2本・3本のような整数で配分します。
- 「管種・用途」で推進用／空伏管（坑内付設用）を指定します。空伏管は推進の日進・完了本数から除外し、専用の使用欄で現場在庫を減らします。

## 継続して使える機能

Microsoft共有接続・案件切り替え、期間別の製造日量、休工日、開始前在庫、日別メモ、バックアップと読込、CSV、月別印刷を保持しています。既存の履歴形式を継続使用し、読込時に実績・日進・休工・施工開始日を初期化しません。

受領工程表は専用JSONを読み込み、案件の `referencePlan` に保存します。具体的な工事の日付や数量を公開ソースへ含める運用にはしません。参照予定を適用すると、製造・出荷・搬入の手入力指定を解除してその予定を使います。実績と施工ペースは保持します。
